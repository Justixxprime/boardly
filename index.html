What's on the board

Built like a real product, not a to-do list demo.

Kanban columns

To do, in progress, done, drag a card between them and the board keeps the story straight.

Real drag-and-drop

Powered by SortableJS, pick up a ticket, drop it anywhere, order is remembered.

Optimistic UI

Add or finish a task and it appears immediately, the server catches up quietly behind it.

Command palette

Press Ctrl+K to add a task or jump anywhere without leaving the keyboard.

Color-coded categories

Work, personal, or urgent, each ticket wears a colored rail so a busy board still scans fast.

Private by default

Supabase row-level security means your account only ever sees your own tickets.

AI board assistant

Ask "what's overdue" or tell it to clear your done column, in plain English, right from the board.

Multiple boards, live sync

Split Work and Personal into separate boards, changes sync instantly across tabs and shared links.

Installable, works offline

Add it to your home screen like a real app, and keep working even with no connection.

Calendar view

Switch from columns to a full month calendar laid out by due date, one click.

Levels and streaks

A real XP bar, daily streak counter, and unlockable badges as you clear tickets.

Reminders that repeat

A focus timer, unit converter, JSON formatter, contrast checker, and a code snippet vault - built in, no other tabs needed.

Several attachments per ticket

Add multiple photos or files, snap one straight from your camera, or paste a copied image in directly.

Process

Three steps, then it's just your board.

01

Create an account

Sign up with an email and password. Boardly opens straight to an empty board, ready to fill in.

02

Write your first tickets

Type a task and hit enter, or press Ctrl+K. Give it a category so it's easy to spot later.

03

Drag it through

Move tickets from To do to In progress to Done. Everything saves and survives a refresh.

Built for the work, not just tasks

One board. Your terminology.

Pick what you're organizing and Boardly relabels itself: the columns, the icons, and the details each task asks for all change to match.

Logistics

Pickup Scheduled → In Transit → Delivered. Customer, address, and driver on every job.

Teaching

Planned → Teaching → Graded. Class, student, and meeting link built in.

Freelance

Client and project on every task, from first draft to delivered.

Field service

Job Scheduled → On Site → Completed. Address and job notes for every visit.

Healthcare / care

Patient, visit address, and notes, logged as each visit gets done.

Personal

Errands, bills, appointments. Set a reminder for a place, not just a time.

Not on the list?

General boards work exactly like a classic to do list, no relabeling. Every vertical here started as one person's actual workflow, and more get added the same way.

FAQ

Questions people actually ask

Is my data private?

Yes, every task row is tied to your account and locked with database-level row security, so no other user can ever read or edit it.

Do I need to install anything?

No, Boardly runs entirely in the browser. Sign up and your board is ready.

Can I use it on my phone?

Yes, the whole interface, including drag-and-drop, is built to work down to a small phone screen.
